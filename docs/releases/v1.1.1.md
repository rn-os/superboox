**SuperBoox 1.1.1**: help for the greyed-out "SuperBoox Quick Access" switch.

On some BOOX tablets (seen on the Note Air 4, firmware 4.2) Android keeps the accessibility switch greyed out for apps installed outside the Play Store, so SuperBoox couldn't be turned on.

- **New tour step, "Get BOOX ready":** allow notifications, Android's battery exemption and BOOX's **Run at startup** before turning the service on. Each row has a button; Next is never blocked.
- **"Switch greyed out?" help** on the "Turn SuperBoox on" step (Android 13+): Open app info → ⋮ → **Allow restricted settings**, then turn the switch on. No developer mode needed.
- The tour is now 11 steps. If you're already set up nothing changes; Settings → Help → Show the tour again has it.

Not yet checked on a tablet: the new tour step and the help card were checked in code and built by CI only.
